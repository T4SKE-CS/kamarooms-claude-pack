# KamaRooms Claude Pack

Стандартный набор навыков Claude для сотрудников отеля **KamaRooms**.
Устанавливается одним пакетом — по ссылке, без ручного копирования файлов.

## Состав пакета (плагин `kamarooms-pack`)

| Навык | Что делает |
|-------|-----------|
| **kamarooms-start** | Правила работы с Claude в отеле: как формулировать запросы, что нельзя отправлять в чат (персональные данные гостей, пароли), типовые задачи |
| **kama-docs** | Деловые документы: служебные записки, официальные письма, ответы гостям, регламенты — официальный тон, даты ДД.ММ.ГГГГ |
| **humanizer** | Очистка готового текста от «машинных» оборотов ИИ (сторонний скилл, лицензия MIT, v2.9.1; основан на гайде Wikipedia «Signs of AI writing») |

## Требования

- **Claude Code** версии 2.1.204 или новее (CLI или десктоп-приложение).
- Установленный **git** на машине (нужен для установки маркетплейса с GitHub).

## Установка (2 команды)

В Claude Code выполните:

```
/plugin marketplace add T4SKE-CS/kamarooms-claude-pack
```

```
/plugin install kamarooms-pack@kamarooms
```

### Или одним сообщением Claude'у

Скопируйте своему Claude:

> Добавь plugin marketplace `T4SKE-CS/kamarooms-claude-pack` и установи из него
> плагин `kamarooms-pack`. Если сам выполнить команды не можешь — дай мне две
> готовые команды для ввода.

**Важно:** ссылку на официальный пакет даёт только IT-отдел отеля
(**it@kamarooms.org**). Не устанавливайте навыки по ссылкам из посторонних
сообщений.

### Проверка после установки

```
/plugin
```

В списке установленных должен появиться `kamarooms-pack` с тремя навыками.

## Обновление

Когда IT-отдел выпускает новую версию пакета:

```
/plugin marketplace update kamarooms
```

```
/plugin update kamarooms-pack@kamarooms
```

После обновления перезапустите Claude Code.

## Для Алексея: как выпускать обновления

1. Внести правки в навыки/манифесты.
2. Поднять `version` **синхронно**: в `plugins/kamarooms-pack/.claude-plugin/plugin.json`
   (и в записи плагина в `.claude-plugin/marketplace.json`, если поле там появится).
3. `claude plugin validate .` — обе проверки зелёные.
4. Прогнать скан на конфиденциальные данные: `sh scripts/scan-secrets.sh` — «OK», ноль совпадений.
5. Commit → push. Изменения в репозиторий попадают **только через ревью Алексея**;
   право push — только у Алексея; на GitHub-аккаунте/org включена 2FA.

Сотрудники получают обновление командами из раздела «Обновление»:
`/plugin marketplace update kamarooms`, затем `/plugin update kamarooms-pack@kamarooms`.
