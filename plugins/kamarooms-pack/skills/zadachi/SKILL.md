# KamaRooms: задачи Битрикс24 одной таблицей

Ты показываешь сотруднику отеля его задачи из Битрикс24 так, чтобы ему не пришлось
заходить в Битрикс. Один запуск — одна свежая сводка: таблица в чате плюс файл
`Задачи Битрикс24.html` на рабочем столе (открывается в браузере, ссылки ведут в задачи).

## Правила, которые не нарушаются

1. **Только чтение.** Разрешённые методы: `profile`, `user.current`, `tasks.task.list`,
   `tasks.task.get`. Ничего не создавать, не менять, не закрывать, не переносить сроки.
   Если сотрудник просит изменить задачу — скажи, что это делается в самом Битриксе
   (или через навык `bitrix24-tasks` для создания).
2. **Ключ не показывать.** Все запросы только через обёртку `b24`; она сама берёт ключ из
   защищённого хранилища. Не читать Связку ключей и файлы ключа напрямую, не `curl`.
3. **Не выдумывать задачи.** В сводке только то, что вернул Битрикс. Пустой ответ — так и
   сказать: «открытых задач нет».
4. **Файл перезаписывается.** Один файл на рабочем столе, каждый запуск обновляет его.
   Ничего никуда не отправлять.

## Шаг 1. Обёртка и «сегодня»

```bash
"${CLAUDE_PLUGIN_ROOT}/skills/bitrix24-tasks/scripts/b24.sh" whoami
```

На Windows без Git Bash: `powershell -NoProfile -ExecutionPolicy Bypass -File "${CLAUDE_PLUGIN_ROOT}\skills\bitrix24-tasks\scripts\b24.ps1" whoami`.

Из ответа возьми `user_id` (мой ID), `portal` и `time.date_start` — это дата и время
сервера в московском поясе, считай их «сейчас». Коды ошибок обёртки: 3 — ключ не найден
(отправь к памятке ИТ: `/kamarooms-pack:bitrix24-tasks настрой Битрикс`), 2 — Битрикс
вернул ошибку (покажи её текст, ключа там нет), 4 — сеть или VPN.

## Шаг 2. Три запроса

Тело запроса — JSON-файл во временной папке; `call tasks.task.list <файл>`.

Открытые задачи — статусы 1 новая, 2 ждёт выполнения, 3 выполняется, 4 ждёт контроля,
6 отложена (завершённые 5 и отклонённые 7 не берём): фильтр `"@REAL_STATUS":[1,2,3,4,6]`.

**Мои задачи, я ответственный:**

```json
{"filter":{"RESPONSIBLE_ID":<мой ID>,"@REAL_STATUS":[1,2,3,4,6]},
 "select":["ID","TITLE","DEADLINE","STATUS","RESPONSIBLE_ID","CREATED_BY","GROUP_ID","CHANGED_DATE"],
 "order":{"DEADLINE":"asc"},"start":0}
```

**Мои задачи, я соисполнитель** (тот же запрос, в фильтре вместо `RESPONSIBLE_ID` —
`"ACCOMPLICE":<мой ID>`). В таблице такие задачи идут в блок «Мои задачи» с пометкой
«соисполнитель» рядом с именем ответственного; одну и ту же задачу не показывать дважды.

**Я поставил другим** (я постановщик, ответственный не я):

```json
{"filter":{"CREATED_BY":<мой ID>,"!RESPONSIBLE_ID":<мой ID>,"@REAL_STATUS":[1,2,3,4,6]},
 "select":["ID","TITLE","DEADLINE","STATUS","RESPONSIBLE_ID","CREATED_BY","GROUP_ID","CHANGED_DATE"],
 "order":{"DEADLINE":"asc"},"start":0}
```

Битрикс отдаёт по 50 задач; если в ответе есть поле `next`, повтори запрос с
`"start": <next>` и дособери список. В каждой задаче уже есть имена: `responsible.name`,
`creator.name`, `group.name` (проект), поля `deadline`, `status`, `title`, `id`.

Статусы в таблице словами: 1 новая, 2 ждёт выполнения, 3 выполняется, 4 ждёт контроля
(в блоке «я поставил другим» это значит «сделали, ждёт вашей проверки»), 6 отложена.

## Шаг 3. Группировка

Сравнивай даты, не время суток (московский пояс, «сегодня» — дата из шага 1). Группы:

1. **Просрочено** — срок раньше сегодняшней даты. Просрочка — полных календарных дней.
2. **Сегодня** — срок сегодня, в любое время.
3. **На этой неделе** — с завтра по воскресенье включительно.
4. **Позже.**
5. **Без срока.**

Внутри группы — по сроку, затем по названию. Просроченные всегда сверху.
Ссылка на задачу: `<portal>/company/personal/user/<мой ID>/tasks/task/view/<ID>/`
(так же строит команда `b24 link <ID>`).

## Шаг 4. Сводка в чат

Заголовок: «Задачи Битрикс24 · Имя Фамилия · ДД.ММ.ГГГГ ЧЧ:ММ». Два блока.

**Мои задачи** — таблица: № · Задача (ссылка) · Срок (ДД.ММ.ГГГГ или «—») · Статус ·
Поставил · Просрочка (дней или пусто). Подзаголовок каждой группы с числом задач:
«Просрочено (3)», «Сегодня (1)»…

**Я поставил другим** — таблица: Задача (ссылка) · Ответственный · Срок · Статус ·
Просрочка. Те же группы.

Итог одной строкой под каждым блоком: «Всего N, просрочено M». Число строк должно совпадать
с суммой `total` из ответов (за вычетом задач, попавших в два запроса). Пустой блок — одна строка
«нет». Ни советов, ни комментариев к задачам: только факты из Битрикса.

## Шаг 5. Файл на рабочем столе

Возьми шаблон `${CLAUDE_PLUGIN_ROOT}/skills/zadachi/templates/zadachi.html`, подставь
вместо `{{...}}` заголовок, дату, строки таблиц (те же группы: строка группы
`<tr class="g"><td colspan="6">Просрочено (3)</td></tr>`, строки задач; просроченные
строки — `class="late"`) и итоги. Сохрани как `Задачи Битрикс24.html` на рабочем столе:
macOS — `~/Desktop/`, Windows — `%USERPROFILE%\Desktop\`. Перезаписывай без вопросов.
В конце скажи: «Файл обновлён: <путь>. Откройте его двойным щелчком, ссылки ведут в задачи».

## Если что-то не так

- Обёртка не найдена или пакет не полностью установлен — предложи `/plugin update kamarooms-pack@kamarooms`.
- Сотрудник просит задачи коллеги или отдела — покажи только то, что видно его ключу
  (Битрикс сам ограничивает права); чужие ключи не запрашивать.
- Сотрудник хочет напоминание по расписанию — это настраивает ИТ (it@kamarooms.org),
  навык этого не делает.
